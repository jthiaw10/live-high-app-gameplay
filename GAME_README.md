# Blaze Runner - 2D Action Platformer

## 🎮 Controls

### Touch Controls (Mobile)
- **Left Button**: Move Blaze left
- **Right Button**: Move Blaze right
- **Jump Button**: Jump (hold for higher jumps)

### Keyboard Controls (Desktop)
- **Arrow Left / A**: Move Blaze left
- **Arrow Right / D**: Move Blaze right
- **Spacebar / Arrow Up / W**: Jump (hold for higher jumps)
