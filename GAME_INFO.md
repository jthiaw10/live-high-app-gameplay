# Blaze Runner - 2D Side-Scrolling Platformer

## Setting
Jamaica 2420 - A futuristic Afro-futurist, reggae-cyberpunk world

## Character
**Blaze** - The protagonist who can run and jump through handcrafted levels

## Controls
- **Left Arrow** - Move left
- **Right Arrow** - Move right  
- **Jump Button** - Jump (hold for higher jump, release early for lower jump)

## Physics System
- **Gravity**: Constant downward force
- **Responsive Movement**: Instant horizontal acceleration
- **Variable Jump**: Jump height based on button hold duration
- **Forgiving Platforming**: Arcade-style collision detection

## Level Design
- **Handcrafted Platforms**: Carefully placed platforms for traversal
- **Environmental Props**: Palm trees and bushes for atmosphere
- **Parallax Background**: Cyberpunk Jamaica cityscape with depth
- **Camera Follow**: Smooth side-scrolling camera tracks player

## Technical Features
- 60fps game loop
- Sprite animation (idle, run cycle)
- Platform collision detection
- Horizontal player bounds
- Touch-optimized controls
